Streamy Panel · Self-hosted

Stasiun Anda, server Anda.

Streamy Panel adalah panel kendali radio internet yang dijalankan di server Anda sendiri: stasiun SHOUTcast, AutoDJ, jadwal, DJ, dan statistik pendengar — tanpa vendor.

Lihat Fitur Detail Teknis

Fitur

Semua yang stasiun butuhkan.

Dari AutoDJ sampai perizinan pengguna — di satu proses Node.

Stasiun sebagai halaman utama

Daftar stasiun dengan status, format, port, dan jumlah pendengar yang diperbarui otomatis tiap 15 detik. Mulai, hentikan, tunda — sekali klik.

AutoDJ 24/7

sc_trans tersupervisi per stasiun: unggah murottal (kuota per stasiun), kelola playlist, dan atur rotasi terjadwal. Lantunan tetap jalan saat tidak ada DJ.

Jadwal & stasiun live-only

Matriks jadwal untuk rotasi AutoDJ. Stasiun live-only juga didukung: DJ tersambung langsung ke sc_serv tanpa AutoDJ.

Kredensial & ban DJ

Kelola akun DJ per stasiun, lihat daftar pendengar yang tersambung secara live, dan ban alamat yang bermasalah dari konsol.

Statistik pendengar

Poller mencatat jumlah pendengar tiap 10 detik dengan retensi 7 hari. Basis data historis milik Anda sendiri, bukan pihak ketiga.

RBAC & operator

Admin mengelola semuanya; operator hanya stasiunnya sendiri. Field sensitif (bitrate, port, kuota) otomatis disembunyikan dari operator.

Detail Teknis

Satu proses, mudah di-deploy.

Dirancang untuk VPS kecil, tanpa orkestrasi yang rumit.

Arsitektur

  • › Node 22 · TypeScript · Fastify 5
  • › Prisma 6 + SQLite — tanpa DB server terpisah
  • › SPA react-admin + API dalam satu proses
  • › Supervisor sc_serv + sc_trans per stasiun

Keamanan

  • › Sesi terkelola, hash argon2 untuk kata sandi
  • › Validasi Zod di seluruh API
  • › RBAC: ADMIN vs USER (operator stasiun)
  • › Suspend stasiun: berhenti total, tak bisa dinyalakan

Operasional

  • › Alokasi port otomatis (rentang dapat diatur)
  • › Unggah media hingga 200 MB, kuota per stasiun
  • › Backup terjadwal via systemd timer
  • › Rilis di balik nginx + TLS, siap produksi
