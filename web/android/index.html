Cara Kerja

Streamy Android · v1.0.0

Siaran langsung dari ponsel Anda.

Streamy Android mengirim suara Anda secara langsung ke server radio internet SHOUTcast — dan tetap bersiaran meski layar mati.

Lihat Fitur Cara Kerja

Fitur

Dibuat untuk tetap siaran.

Semua di bawah ini hadir di v1.0.0 — ditulis untuk manusia, bukan protokol.

Ke server radio sungguhan

Protokol sumber SHOUTcast v2 yang asli — standar di balik ribuan stasiun radio internet. Teruji langsung terhadap DNAS 2.6.1.

Kualitas audio pilihan Anda

MP3 dari 16 kbps yang ramah suara hingga 192 kbps kelas studio. Pilih bitrate, laju sampel, serta mono atau stereo.

Tetap siaran di latar belakang

Layanan latar depan menjaga mikrofon dan koneksi tetap hidup saat layar mati — dan menyambung ulang setelah sistem menutup aplikasi.

Putus? Menyambung ulang otomatis

Mencoba ulang otomatis dengan jeda yang makin lama antarpercobaan — ditambah tombol hentikan sekali sentuh saat Anda ingin berhenti.

Judul now-playing, tanpa login admin

Ketik nama surat, qari, atau acara saat siaran, dan pendengar melihatnya seketika. Tanpa perlu kata sandi admin server.

Lihat suara Anda sebagai gelombang

Osiloskop real-time dan meter VU yang digambar langsung dari sinyal mikrofon Anda, menyala seperti lampu tally siaran.

Simpan beberapa stasiun

Simpan profil untuk tiap server — host, port, kata sandi, dan pengaturan audio — lalu beralih di antaranya.

Konsol yang terasa seperti konsol

Desain lampu tally: tinta pekat, merah on-air, dan readout monospace. Dirancang agar enak dipakai di tengah siaran.

Cara Kerja

Dari suara Anda ke telinga mereka.

Empat langkah, berjalan terus selama Anda siaran.

01

Anda bicara

Mikrofon ponsel Anda menangkap suara Anda.

02

Streamy menyandikan

Ia memampatkan suara Anda menjadi audio MP3 secara real-time.

03

Dikirim ke server Anda

Audio mengalir melalui internet menuju server SHOUTcast v2 Anda.

04

Pendengar mendengarkan

Siapa pun yang tersambung ke server itu mendengar Anda, secara langsung.

Catatan Perubahan

Log transmisi.

Apa yang dirilis, dan apa yang diperbaiki sejak itu.

Catatan rilis streamy-app.pages.dev

v1.0.0 Rilis awal · 2026-07

  • >Suara langsung → SHOUTcast v2 melalui protokol sumber Ultravox 2.1 yang asli.
  • >MP3 pada 16, 24, 48, 64, 96, 128, dan 192 kbps.
  • >Siaran latar belakang yang bertahan saat layar mati maupun saat aplikasi dikecilkan.
  • >Penyambungan ulang otomatis dengan kendali hentikan secara manual.
  • >Judul now-playing tanpa login admin server.
  • >Meter VU osiloskop sungguhan di layar siaran.
  • >Profil beberapa stasiun dengan pengaturan audio per profil.
  • >Dropdown bitrate, laju sampel, dan kanal.

Catatan: enkoding AAC sudah diimplementasikan tetapi disembunyikan di rilis ini — sedang ditinjau ulang.

Perbaikan Setelah v1.0.0

  • >Audio bitrate rendah (16 / 24 kbps) kini melaporkan kualitasnya dengan benar.
  • >Terhubung ke server berbasis Centova / sctrans2 (memakai kunci cipher milik tiap server).
  • >Stabilitas AAC ditingkatkan lewat framing ADTS (sementara masih disembunyikan di UI).
