Kebijakan Privasi

Terakhir diperbarui: 13 November 2026

Ringkasan: Streamy adalah alat siaran. Audio mikrofon Anda hanya dikirim ke server radio internet yang Anda sendiri tentukan. Pengembang Streamy tidak mengumpulkan, menyimpan, atau menerima data pribadi apa pun dari Anda.

1. Data yang diproses aplikasi

  • Audio mikrofon. Saat Anda menekan tombol siaran atau rekam, aplikasi menangkap suara mikrofon Anda. Audio disandikan menjadi MP3 di perangkat Anda, lalu dikirim secara langsung ke server SHOUTcast/Icecast yang Anda masukkan sendiri (host, port, dan kata sandi yang Anda atur). Audio tidak melewati server pengembang.
  • Judul siaran. Jika Anda mengatur judul lagu/acara, teks tersebut dikirim ke server radio yang sama.
  • Rekaman. Fitur perekam menyimpan file MP3 secara lokal di penyimpanan perangkat Anda. Rekaman tidak diunggah ke mana pun.
  • Profil server. Host, port, dan kata sandi server disimpan secara lokal di basis data perangkat (Room) dan tidak dikirim ke pengembang.

2. Data yang dikumpulkan pengembang

Tidak ada. Streamy tidak memiliki akun, tidak memasang analitik atau iklan, tidak melacak penggunaan, dan tidak mengirim telemetri apa pun kepada pengembang.

3. Izin aplikasi

  • Mikrofon — untuk menangkap suara siaran/rekaman.
  • Internet & status jaringan — untuk menyambung ke server radio Anda dan menyambung ulang saat koneksi terputus.
  • Layanan latar depan & wake lock — agar siaran tetap berjalan saat layar mati.
  • Notifikasi — untuk menampilkan indikator siaran yang sedang berjalan.

4. Pihak ketiga

Aplikasi hanya berbicara dengan server yang Anda tentukan sendiri. Selain itu, versi yang didistribusikan di luar Google Play dapat memeriksa pembaruan dari GitHub Releases (hanya versi dan tautan unduhan; tidak ada data pengguna yang dikirim). Versi Google Play tidak memeriksa pembaruan sendiri — pembaruan datang melalui Google Play.

5. Privasi anak

Streamy tidak ditujukan untuk anak di bawah 13 tahun dan tidak dengan sengaja mengumpulkan data dari anak-anak.

6. Perubahan kebijakan

Jika kebijakan ini berubah, versi terbaru akan dipublikasikan di halaman ini dengan tanggal pembaruan di atas.

7. Kontak

Pertanyaan tentang privasi dapat disampaikan melalui email pengembang yang tercantum pada halaman aplikasi di Google Play, atau melalui repositori proyek di GitHub.
